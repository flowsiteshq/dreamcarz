# ElevenLabs Concierge Speech-to-Text Integration Note

The official ElevenLabs Speech-to-Text API accepts `POST https://api.elevenlabs.io/v1/speech-to-text` as a multipart request with exactly one audio file or cloud-storage URL. WebM is a supported audio format. DreamCarz should use short browser-recorded WebM audio, send it through a server-side credential boundary, accept only the returned text into the existing Concierge conversation, and avoid persisting the audio or transcript separately from the customer’s normal Concierge flow. The official capability documentation also describes the realtime model and no-verbatim option; the first release will use a short post-recording transcription request rather than maintaining a long-lived realtime audio stream. Sources: https://elevenlabs.io/docs/api-reference/speech-to-text/convert and https://elevenlabs.io/docs/overview/capabilities/speech-to-text.
