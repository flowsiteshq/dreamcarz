# DreamCarz Staff Email Alerts

## Purpose and scope

This feature sends a **staff-only email alert** when a prospective customer grants contact consent or an Associate enrollment is verified and activated. It never emails customers, creates no accounts, and keeps customer contact details, payment information, form answers, access tokens, and passwords out of the alert.

The DreamCarz application records an idempotent, durable outbox entry for each event. A unique delivery key prevents duplicate alerts. The outbox uses a stable internal recipient hash rather than storing the recipient email address, and failures are retained for bounded retry through the existing one-shot Railway retry worker.

## Triggered events

| Event | When the alert is queued | Email content |
| --- | --- | --- |
| Marketing opt-in | A public advertising lead submits the required contact-consent form, or a new non-test Meta/Zapier lead is created. | Safe lead reference/ID and an instruction to review the protected Admin portal. |
| Associate opt-in | An active Associate captures a consented lead in the Associate portal. | Safe lead ID and an instruction to review the protected Associate portal. |
| Associate enrollment activated | The hosted $149 enrollment payment and $49 monthly subscription are provider-verified and Associate access is activated. | Safe enrollment reference and an instruction to review the protected Admin portal. |

## Zapier delivery configuration

Create a separate Zap with the following two steps:

| Step | Configuration |
| --- | --- |
| Trigger | **Webhooks by Zapier → Catch Hook**. Copy the generated HTTPS hook URL. |
| Action | **Email by Zapier → Send Outbound Email**. Set **To** to `www.dreamcarz.io@gmail.com`; subject should use the webhook `subject` field and body should use the webhook `message` field. |

After the Zap is published, add these server-only Railway variables to the DreamCarz web service:

| Variable | Required value |
| --- | --- |
| `STAFF_EMAIL_ALERTS_ENABLED` | `true` |
| `STAFF_EMAIL_ZAPIER_HOOK_URL` | The exact HTTPS Catch Hook URL generated by Zapier. |

The application accepts only HTTPS `hooks.zapier.com` URLs. The hook URL remains server-only and is never placed in the frontend, source control, screenshots, or chat.

## Verification

Submit one controlled consented lead. Confirm that one email arrives at `www.dreamcarz.io@gmail.com` containing only the safe source reference/ID, and verify the matching outbox entry is marked `sent`. Re-run only the controlled duplicate path and confirm no second email is generated for the same event.

> Do not use a real customer’s information for verification. The feature is an internal staff alert and is not customer-facing marketing email.
